# 01.07 Subprocess Supervision and Process-Tree Containment

Roadmap priority 7. Grounds Phase 8 local tools and Phase 17 shell execution in real operating-system cleanup behaviour.

## Purpose

Determine reliable Go patterns for starting, observing, cancelling, timing out, and reaping subprocess trees while bounding descriptors, environment, working directory, output, and privileges.

## Steps

- Trace process creation, command context, environment construction, working directory, stdin, stdout, stderr, and exit classification.
- Inspect Unix process groups, Windows job objects or equivalents, signal escalation, and descendant termination.
- Check pipe draining, output bounds, descriptor closure, child reaping, and cancellation during startup.
- Examine containment boundaries such as namespaces, cgroups, containers, and explicit non-guarantees.
- Find cross-platform tests for orphaned children, hung pipes, races, timeout, and forced termination.

## Questions

- Does cancelling the parent guarantee that descendants stop?
- Can unread output deadlock process completion or exhaust memory?
- Which containment claims hold on each supported operating system?
- How are exit status, timeout, cancellation, setup failure, and cleanup failure distinguished?
